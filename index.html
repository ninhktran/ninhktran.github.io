02 Personal project / Gemini-generated window previews Windows Visualizer Gemini analyzes a room photo, pinpoints the window opening, and generates a photorealistic replacement-window image right inside it — finished with live color swaps in the browser. FastAPIGemini visionGemini image genCanvas chroma key Open project details+

In short: upload a photo of your room, pick a window style, and see an AI-rendered replacement window sit in the real opening of your room — then flip through paint finishes without re-rendering. A FastAPI backend runs the AI work; the browser only composites and recolors.

Problem

Homeowners make expensive remodeling decisions without seeing how a new window will look inside their actual room and lighting. Static catalog photos never match the space.

Build

Upload goes to FastAPI, which asks Gemini 2.5 Flash vision for the window opening as normalized polygon coordinates plus a confidence score. A second call — Gemini 2.5 Flash Image — edits the original photo directly: it preserves the room, camera angle, walls, and lighting, renders the chosen window style in the detected opening, and paints only the frame pure magenta (#FF00FF) for downstream chroma keying. If no model is available, the server falls back to deterministic geometry and draws a centered window outline itself. Jobs are keyed server-side, expire after an hour, and no AI key ever reaches the browser.

Result

One upload yields ten window styles rendered in place. The browser canvas shader chroma-keys the magenta out, composites the window into the photo with luminance preserved, swaps finishes instantly and locally, and exports a PNG before/after comparison.
